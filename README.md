## 项目

### 01 · 秋招助手 · 求职投递管理 + AI 提效

面向海投阶段的应届生求职者，解决投递进度难以跟踪、企业回复邮件容易遗漏、周报与面试准备重复劳动的问题。主要功能：

- 五分区看板跟踪投递进度：待投递、待推进、只投了简历、已推进、已完成
- IMAP 自动识别企业回复邮件，判定测评、笔试、面试、offer、拒绝、调剂，自动更新阶段
- AI 生成周报、选岗建议、面试准备、作品集识别
- 临近截止自动高亮，需要作品集的岗位标注徽标
- 网页版与 Electron 桌面版双端，真实数据与演示数据完全隔离

- 在线演示：http://119.28.16.198:8001
- 源码仓库：https://github.com/LinYinLai/job-tracker

### 02 · instax 拍立得 · AI 滤镜 + 反即时满足

以富士 instax mini 7c 为原型的互动拍立得网页，面向偏好复古、胶片审美的年轻用户。主要功能：

- 3D 相机按下快门输出相纸
- 相纸拖入取景框后 90 秒显影，摇晃鼠标最多可三倍加速
- 输入相机型号，AI 联网检索该机型的发色特征，生成 7 个可微调的滤镜参数
- 无 API Key 时亦可通过内置预生成滤镜卡体验
- 收藏墙与模板管理，单文件构建、双击即开

- 在线体验：https://instax-room.netlify.app（加 `?demo=1` 显影压到 5 秒）

### 03 · DICS Records · 3D 唱片墙 + 唱机

将 12 张专辑组织为可交互的 3D 唱片墙，面向偏好实体唱片质感与音乐体验的用户。主要功能：

- 3D 弧形旋转木马浏览专辑
- 点击中心碟片进入唱机模式，播放音频并显示歌词金句
- 自制 CD 上传，IndexedDB 持久化，刷新后重建
- 通过 iTunes 搜索自动获取封面与音频
- 提取封面主色驱动唱机背景渐变

- 在线体验：http://119.28.16.198

### 04 · 梦核房间 · 个人主页

中式梦核风格的互动房间个人主页，将简历与项目信息融入房间场景，面向访问主页的招聘方与访客。主要功能：

- 贴纸 hover 浮起
- 猫以五段演出串联内容：简历、工牌、拍立得、CD 机、碟片
- 电视三频道循环：雪花、PM5544 测试卡、加菲猫
- 百叶窗昼夜系统，拖拽实时调节明暗
- 工牌 3D 翻转（reactbits Lanyard 移植，自研绳物理）

- 在线体验：https://portfolio-lightning.netlify.app
