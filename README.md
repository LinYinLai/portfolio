## 项目

### 01 · 秋招助手 · 求职投递管理 + AI 提效工具

面向海投阶段的应届生求职者，首版为本人自用。秋招同时投递数十家企业，进度依赖 Excel 手工记录，难以结构化且容易混乱；企业回复邮件需逐封人工检查，容易遗漏；周报与面试准备存在重复劳动。现有求职工具多聚焦提升投递效率，投递之后的进度管理与复盘环节相对空白。基于此，项目定位在投后管理：优先解决投递进度可视化、邮件自动识别与 AI 提效，暂缓自动投递、岗位推荐、简历定制等存在数据与渠道壁垒的需求。

产品提供五分区看板跟踪投递进度，IMAP 自动识别企业回复邮件并判定测评、笔试、面试、offer、拒绝、调剂，以及 AI 生成周报、选岗、面试准备、作品集识别四个入口。用户路径为投递记录、看板跟踪、邮件自动更新阶段、AI 生成。关键取舍是 AI 采用固定入口而非自由对话，使输入可校验、可脱敏、成本可控；真实数据与演示数据通过 DEMO_MODE 完全隔离，线上演示使用虚构企业。

- 在线演示：http://119.28.16.198:8001
- 源码仓库：https://github.com/LinYinLai/job-tracker

### 02 · instax 拍立得 · AI 滤镜互动网页

面向偏好复古、胶片审美的 18–28 岁年轻用户。主流滤镜应用追求即时反馈与高度可编辑，削弱了拍立得"仅此一张、等待显影"的仪式感；AI 滤镜多为黑盒，用户难以理解参数来源。项目以"反即时满足"为差异化定位，优先解决显影仪式感与 AI 滤镜可解释性，暂缓登录、云端收藏与社群功能。

产品以富士 instax mini 7c 为原型，提供 3D 相机出片、90 秒显影（摇晃鼠标加速）、AI 相机型号到滤镜参数映射、收藏墙与模板管理。用户路径为上传照片、调色、烘焙、出片、显影、收藏。关键取舍是调色在拍摄前烘焙为新底图，使下游模块零改动；AI 输出经 JSON 与参数范围校验；无 API Key 时以内置预生成滤镜卡降级。

- 在线体验：https://instax-room.netlify.app

### 03 · DICS Records · 3D 唱片墙 + 唱机

面向偏好实体唱片质感与音乐体验的用户。主流流媒体以列表呈现音乐，缺少实体唱片"取出、放入唱机"的仪式感。项目以这一仪式感为核心体验，优先解决 3D 交互浏览、唱机播放与自制 CD 上传，暂缓完整曲目播放（受版权限制，采用 iTunes 30 秒试听）与艺术家子页。

产品提供 12 张专辑的 3D 弧形旋转木马、唱机模式（播放与歌词金句）、自制 CD 上传与 iTunes 自动抓取。用户路径为拖拽浏览专辑、点击中心碟片进入唱机、播放。关键取舍是封面不直接映射 GLB 的 UV，改以 RingGeometry 环形印刷层叠加；唱机高速旋转通过贴图模糊实现，而非真实超高转速。

- 在线体验：http://119.28.16.198

### 04 · 梦核房间 · 互动个人主页

面向访问个人主页的招聘方与访客。个人主页通常由信息卡片与自我介绍构成、形式单一。项目以中式梦核风格为差异化，将简历与项目融入房间场景，优先解决氛围营造与内容串联，暂缓音效与更多彩蛋。

产品提供贴纸 hover、猫的五段演出、电视三频道循环、昼夜系统与工牌 3D 翻转。用户路径为进入房间、猫按脚本演出、跳转到对应项目。关键取舍是猫采用换装皮影方案（六张姿态抠图配合 CSS 位移）；工牌移植 reactbits 的 Lanyard 3D，自研绳物理与程序化织带。

- 在线体验：https://portfolio-lightning.netlify.app
